# Лабораторная работа №3 — DES-CBC

**Буслаев Роман Витальевич. Вариант 2.**

Учебная программа на C# / Windows Forms: DES, расписание подключей, CBC и PKCS#7 реализованы вручную. Можно зашифровать и расшифровать файл любого формата, выбрать исходный файл и файл назначения, ввести пароль с клавиатуры или прочитать его из файла. Во второй вкладке находится описание алгоритма.

## Запуск

1. Склонируйте репозиторий или скачайте исходники.
2. Откройте `Lab3_DES_CBC.slnx` в Visual Studio с поддержкой формата `.slnx` и компонентом «Разработка классических приложений .NET».
3. Назначьте проект **DesLab** запускаемым и нажмите **F5**. Проект **Checks** предназначен для консольных проверок.

Приложение предназначено для Windows и использует .NET 8 Windows Forms. Для команд сборки ниже используйте **.NET SDK 10**, поддерживающий `.slnx`; для запуска также нужна **.NET Desktop Runtime 8**. Готовые исполняемые файлы в репозиторий не включаются — они создаются при сборке.

## Как устроено шифрование

- Ключ: первые 8 байт SHA-256 от пароля в UTF-8, затем установка нечетной четности каждого байта. Из 64 бит ключа DES использует 56.
- Пароль из файла: непустая строка UTF-8, файл до 4096 байт. Допускаются BOM и один завершающий перевод строки; пробелы сохраняются.
- Блок DES: 8 байт, начальная перестановка, 16 раундов Фейстеля, конечная перестановка. При расшифровании подключи используются в обратном порядке.
- CBC: перед шифрованием открытый блок складывается по XOR с предыдущим шифроблоком; для первого блока используется случайный IV.
- PKCS#7: добавляется от 1 до 8 байт, каждый равен количеству добавленных байт. Даже при длине, кратной 8, добавляется полный блок.
- Формат результата: **8 байт IV + шифротекст DES-CBC/PKCS#7**. IV создается заново при каждом шифровании и хранится открыто.
- Результат сначала пишется во временный файл и заменяет назначение после успешной обработки.

## Состав комплекта

| Папка | Содержимое |
| --- | --- |
| `Lab3_DES_CBC.slnx` | Решение с проектами DesLab и Checks |
| `src` | Полный исходный код приложения и проект |
| `checks` | Консольная проверочная программа |
| `samples` | Учебные файлы и пример пароля |
| `evidence` | Фактические результаты проверок и трассировка 16 раундов |

Отчет с блок-схемами, расчетом первого раунда, листингом и скриншотами предоставляется отдельно от репозитория.

## Сборка и проверка

Команды выполняются в корне репозитория:

```powershell
dotnet build Lab3_DES_CBC.slnx -c Release
dotnet run --project src/DesLab.csproj
```

Отдельная команда для проверки алгоритма без открытия окна:

```powershell
dotnet run --project checks/Checks.csproj -c Release -- .
```

Проверочная программа не открывает графическое окно. Она обрабатывает файлы в `samples`, создает служебные примеры в `evidence/check-files` и записывает результаты в `evidence/checks.json` и `evidence/rounds.json`.
